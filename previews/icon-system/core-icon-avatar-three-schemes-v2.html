工作流 / 对话 Agent / 对话 Agent V2 / 知识库 / 工具 / 插件 —— A/B/C 基于 currentColor 单色体系；D/E/F 为彩色方向，延续工作流节点方案 I（多彩）的资源专属色语言。

说明：彩色三套为工作流节点多彩例外的延伸探索，图形内为固定色值，不随 currentColor 变化；生产采纳时按交接文档登记例外执行，单色规范仍以 A/B/C 为准。

20×20 viewBox · round cap 与已替换的 12 个配置图标同一规格，可无缝落入 MyIcon 现有调用。
currentColor 单色 双色调/实点层全部使用透明度而非固定颜色，亮暗模式、主题色切换自动生效。
V1 / V2 靠形态区分 不依赖颜色或角标：V1 = 对话气泡点眼，V2 = 机器人头，小尺寸依然可分辨。

stroke 1.5 currentColor 无填充层 现有体系延续

方案 B · 蓝图双色调（Blueprint Duotone）

stroke 1.5 双层 currentColor opacity 12–18% 饱满但不花

方案 C · 节点实点（Solid Node）

主线加粗到 1.75，并把“关键元素”转化为实心圆点：工作流的起点、Agent 的天线端、知识库的索引点。 实点是 OmniCockpit 的签名语法，传达“节点已就绪/已激活”，性格比 A/B 更鲜明、更工作台化。

stroke 1.75 currentColor 实心几何点 品牌签名语法

方案 F · 深浅双色（Tint & Tone）

主体用资源色的浅档（Tint），关键元素用同族深档（Tone），靠同族两档深浅建立视觉权重： 比 D 更安静、比 E 更锐利，是最耐看的彩色版本，高密度列表下噪点最低。

stroke 1.5 同族深浅两档 无铺底层 低噪点彩色

定稿后的落地路径（遵循交接文档约定）

  1. 选中方案后，直接替换共享 SVG 资产：packages/web/components/common/Icon/icons/core/app/type/ 下的 workflow.svg / agent.svg / simple.svg / plugin.svg / httpPlugin.svg / mcpTools.svg 及对应 Fill 版本，既有 MyIcon 调用自动生效，不在页面局部复制图标。
  2. Agent V2 需新增资产并接入应用类型选择器；V1/V2 区分只靠形态（气泡 → 机器人），不靠颜色或角标。
  3. 方案 B 的双色调层必须用 fill="currentColor" + opacity 实现，禁止写死色值， 确保主题色与深色模式自动适配。
  4. 头像保持无底色：资源默认头像直接裸露呈现图形，不加暖金/渐变底块；如需容器只允许 1px 描边或 hover 时 8% 品牌蓝光环，避免误伤占位头像与聊天角色状态。
  5. 命名建议 icon-{type}-{variant}（如 icon-agent-v2）；替换后对 Dashboard、 应用轨、工作流节点坞等高曝光面做一轮截图 QA。
