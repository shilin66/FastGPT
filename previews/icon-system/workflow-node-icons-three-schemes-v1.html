工作流节点图标 · 三套重设计方案

范围：节点库 29 个模板节点图标（AI 能力 / 交互 / 工具 / 流程控制）。现状为彩色渐变底块（FastGPT 痕迹）。
三套方案均遵循 OmniCockpit 规范：20×20 viewBox · currentColor 单色 · stroke 1.5 · round cap/join · 无底色 · 光学居中（占位 68–77%）。差异仅在图形语言的性格。
方案 A · 精线单色（Line Mono）：纯线稿，与已落地的核心资源图标完全同族，高密度列表最安静。
方案 B · 双调面光（Duo Tone）：线稿 + 主形体 10% 同色面光，画布上层次更饱满，仍严格单色。
方案 C · 实点签名（Solid Accent）：线稿 + 语义关键点实心化（播放钮/菱形/旋钮/箭头），识别签名最强。

方案 A · 精线单色（Line Mono）与已落地核心资源图标同族 · 高密度列表最安静

纯线稿，无面光无实点。适合：节点库列表、大画布多节点场景，视觉噪声最低。弱点：同形图形间靠细节区分，16px 下略轻。

方案 B · 双调面光（Duo Tone）线稿 + 10% 同色面光 · 画布层次更饱满

主形体铺 10% currentColor 面光，仍严格单色、无彩虹。适合：节点画布，拖拽选中的节点体积感更强。弱点：密集列表下比 A 略噪。

方案 C · 实点签名（Solid Accent）线稿 + 语义关键点实心化 · 识别签名最强

将每个节点的“语义锚点”实心化：开始/运行的播放钮、判断菱形、参数旋钮、箭头、停止块。适合：需要快速扫读定位节点类型的场景。弱点：实点在极小尺寸（<14px）下可能糊成团。
