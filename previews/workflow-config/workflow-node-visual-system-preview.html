落地范围

先改公共节点外壳、标题区、输入输出区和动态字段样式，不迁移配置逻辑，不改保存结构。

视觉原则

灰阶信息层级承载内容，饱和蓝只用于选中、连接线、关键状态和品牌识别，避免回到 FastGPT 原始风格。

风险控制

HTTP、Agent、Code、Loop 等复杂节点只做包裹和间距统一，保留内部业务控件，减少功能回归。
